# URUKORA roadmap

1. **Foundation (v0.1):** /start, bilingual Mini App, verified Telegram initData, local QR generation, tests.
2. **Files (v0.2 implemented):** browser-only PDF merge and page extraction, image conversion and resize, size/page limits, local activity metadata. **Planned:** server jobs, scanned PDF OCR and advanced conversions.
3. **Productivity (v0.4):** One-off reminders via Telegram bot commands and verified Mini App create/list/cancel; SQLite persistence, retries, idempotency keys, owner-only access. **Planned:** recurring jobs, explicit timezone schedules, long-running hosting and delivery metrics.
4. **Channels:** Authorized connection and scheduled publishing, admin-right checks, auditing.
5. **Public readiness:** secure sessions, admin RBAC, operational logs, quotas, monitoring, backup and privacy policy.
6. **Extensions:** AI features, safe moderation, visual automation builder, subscriptions.
